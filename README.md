# ⚡ BrainBlast — JavaScript Quiz Ilovasi

JavaScript bilimlarini sinab ko'rish uchun interaktiv quiz o'yini. Vanilla HTML, CSS va JavaScript bilan qurilgan.

## 🎮 Demo

Fayllarni yuklab, `index.html` ni brauzerda oching — tayyor!

## ✨ Xususiyatlari

- **10 ta savol** — O'zgaruvchilar, Array, Funksiyalar, va boshqalar
- **30 soniyalik taymer** — Har bir savol uchun, rang bilan o'zgaradi
- **Ball tizimi** — Tez javob bersangiz ko'proq ball olasiz
- **Animatsiyalar** — Silliq o'tishlar va micro-interaksiyalar
- **Natija ekrani** — Ball, foiz, statistika
- **Nusxalash** — Natijangizni do'stlaringizga yuboring
- **Responsiv dizayn** — Telefon va kompyuterda ishlaydi

## 🛠 Texnologiyalar

- HTML5
- CSS3 (CSS Variables, Animations, Grid)
- Vanilla JavaScript (ES6+)
- Google Fonts (Syne + DM Sans)

## 📝 Savol qo'shish

`script.js` faylidagi `questions` massiviga yangi ob'ekt qo'shing:

```js
{
  category: "Kategoriya nomi",
  text: "Savol matni?",
  options: ["Variant A", "Variant B", "Variant C", "Variant D"],
  correct: 0,  // to'g'ri javob indeksi (0 = A, 1 = B, ...)
}
```
